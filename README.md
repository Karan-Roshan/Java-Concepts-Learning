## How to Run a Program

1. Install a Java Development Kit (JDK).
2. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Java-Concepts-Learning.git
   ```

3. Open the repository directory:

   ```bash
   cd Java-Concepts-Learning
   ```

4. Compile a source file. For example:

   ```bash
   javac constructor.java
   ```

5. Run the class using the class name declared in the source file. For example, if the class is named `constructor`:

   ```bash
   java constructor
   ```

**Note:** Java class names are case-sensitive. The class name used in the run command must match the class declared in the source code. Some examples may need to be compiled with other source files if they depend on additional classes.
